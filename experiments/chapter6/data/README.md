# 第六章实验数据说明

## 数据来源

本实验所有数据基于 **深圳妈湾港（MCT）2024年全年真实运营数据**，经港口侧脱敏后用于仿真验证。

原始运营数据通过夸克网盘获取（见仓库根目录 `Data_Availability_Statement.md` 与 `README.md` 数据可用性声明），包含：

| 文件 | 内容 |
|:---|:---|
| `1 2024年MCT船舶基本资料.xlsx` | 船舶资料（~5,900艘） |
| `2 2024年MCT典型船舶贝位结构.csv` | 典型船舶贝位结构 |
| `3、2024年MCT船舶靠离泊计划.xlsx` | 靠离泊计划 |
| `4 2024年MCT出口集装箱清单及5 装船位置.xlsx` | 出口清单（上/下半年） |
| `6 MCT堆场箱位定义.xlsx` | 堆场箱位定义 |
| `8 2024年MCT集装箱移动事件流.xlsx` | 移动事件流（上/下半年） |
| `7 2024年MCT堆场快照/` | 堆场逐日快照（xce.dmp） |

## 预处理数据

清洗后数据存于 `01_data/processed_data/`（parquet），仿真输入见 `02_code/simulation/`；标准化结果与论文表6.1-6.4对应文件见 `03_results/canonical/sim_all_cfgall_d30r10.parquet`。
