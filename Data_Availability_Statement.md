# Data Availability Statement

**Research:** Digital Twin-Driven Collaborative Optimization of Container Port Stowage and Yard Operations

**Data Source:** Shenzhen Mawan Port (MCT) 2024 operational data
(including 1.05M container movement records, vessel schedules, and yard structure with 246,856 slots)

**Restrictions:** The original raw data is included with this package for review and academic verification purposes, subject to the data use agreement with the port operator.

**What is included in this package:**
1. Desensitized canonical experiment datasets (parquet format) in `03_results/canonical/`
2. Complete Python/PyTorch source code to reproduce all figures and tables
3. The column schemas and statistical summaries of original data (see `01_data/codebook/`)
4. MAS-DES simulation platform code

**Accessing the original data:**
Researchers interested in accessing the original desensitized data may contact the corresponding author. Access requests require approval from the port operator and a signed data use agreement.

# 数据可用性声明

**研究项目：** 基于数字孪生的集装箱港口配载与堆场协同优化研究

**数据来源：** 深圳妈湾港（MCT）2024年运营数据
（含105万条集装箱移动记录、船舶靠泊计划、堆场246,856箱位结构参数）

**限制说明：** 根据数据使用协议，原始数据随复现包一并提供（受协议约束，仅限审稿与学术验证用途）。

**本复现包包含：**
1. 脱敏后的规范化实验数据集（parquet格式），位于 `03_results/canonical/`
2. 复现论文所有图表和实验结果的完整 Python/PyTorch 源代码
3. 原始数据字段结构说明与统计摘要（见 `01_data/codebook/`）
4. MAS-DES 仿真平台完整代码

**数据获取：** 有数据访问需求的科研人员可通过通讯作者申请获取脱敏原始数据，申请需经港口管理方审批并签署数据使用协议。
